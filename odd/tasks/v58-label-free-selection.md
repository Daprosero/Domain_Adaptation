Objective: implement protocol v58 §4.5 phase-2 model selection with no target labels (centroid primary rule, EnsV secondary) in `src/MIL_CREDA_EEG`, and rebind code provenance v57 -> v58.

## Specs

- **S1. No target label in phase-2 selection.** Operator, 2026-11-06: "de ehcho sin nada de etiquetas para no tener problemas". No phase-2 selection decision (trial, epoch, secondary choice) reads a target label. The target-labelled rule (`pooledBalancedAccuracy` over target subjects) and the entropy rule (`pooledLabelFree`, `label_free_score`, `LabelFreeBest`, `with_label_free`, `LABEL_FREE_EPOCH_RULE`) are removed from phase-2 selection. Phase 1 (source labels) is unchanged. `controls.py`'s target-supervised upper bound is a reference, not a selection, and stays.
- **S2. Primary rule: centroids** (v58 §4.5, verbatim source: /Users/diego/Proyectos/MIL-CREDA/experiments/experiments-plan-experimental-mil-creda-sobre-balladeer-v58.md, section "### 4.5 Selección de hiperparámetros"). Per trial, epoch and inner split: the adapted model predicts the target bags of the validating fold (pseudo-label = argmax); keep each bag's representation Z (the vector entering the predictive head); one centroid per pseudo-label class (a class with no bag has no centroid); the validating fold's source bags go through the frozen source encoder + the same frozen attention/aggregator; each is assigned to the nearest centroid (Euclidean); confusion counts against the real SOURCE labels are pooled over the three inner splits and balanced accuracy is computed once; argmax over (trial, epoch). Collapse to one class gives 0.5 with two classes. Source representations are computed once per (rotation, inner split) and reused. Works in the device arm (29 vs 14 channels; both encoders write the shared 256-d space).
- **S3. Secondary rule: EnsV** (v58 §4.5). Within one strategy's study in one rotation, candidates = all (trial, epoch) pairs; for each target bag of F, predicted once from the inner split where it validates, average the predicted probabilities over all candidates -> role-model pseudo-label (argmax); each candidate scores its accuracy against those pseudo-labels; argmax. No extra training. Where it picks a different (configuration, epoch) than the primary, phase 2 is refit with the reporting seed (as the old label-free refit did); where they coincide, the primary model is reused.
- **S4. Two-rules table** (v58 §4.5): columns "Configuración de la regla principal", "Configuración de la regla secundaria", "Coinciden", "Exactitud balanceada de prueba, regla principal", "Exactitud balanceada de prueba, regla secundaria", "Diferencia"; class proportions of the source and target sides of each core transfer reported beside it (v58 §8).
- **S5. CLUST** source-free trainer never reads source data; the centroid rule's source pass runs in `search.py`, outside the trainer (v58 §7.3).
- **S6. Provenance** strings bound to protocol v57 move to v58 (text-only; `partition.py` excluded as in the v57 rebind); tests pinning the plan revision updated.
- **S7. No added search training** (v58 §7.7): the rules add no training run to the search.
